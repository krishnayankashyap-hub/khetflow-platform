# Security Policy

## Supported Versions

The following versions of KhetFlow are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within KhetFlow, please do not open a public issue.

Instead, please email security advisories to the maintainers at **krishnayankashyap.dev@gmail.com**.

Please provide:
- Description of the vulnerability
- Affected portal / component
- Steps to reproduce or proof of concept
- Potential impact

We will acknowledge receipt within 48 hours and work with you to patch and coordinate disclosure.
